# 数据生成质量评估
采用三种互补的评估方法：LLM Judge、Win Rate 和人工打分

LLM Judge 和 Win Rate 用于评估题目生成质量（从正确性、清晰度、难度匹配等维度进行多维度评估）

而人工打分用于评估答案生成质量（通过人类专家验证答案的准确性）


# LLM Judge 评估
使用大语言模型作为评委，可以自动化地从多个维度评估生成数据的质量，不仅大幅提升评估效率，还能保持评估标准的一致性

从四个关键维度评估：每个维度都是1-5分
1、正确性：数学逻辑是否正确，答案是否准确
2、清晰度：问题表述是否清晰，解答是否易懂
3、难度匹配：难度是否符合标准
4、完整性：解答步骤是否完整，是否包含必要的推理

评估指标：
1、平均分
    计算所有题目在四个维度上的平均得分，反映生成题目的整体质量水平
2、及格率
    统计平均分达到 3.5 分及以上的题目比例，反映生成题目的基本质量保障。
3、优秀率
    统计平均分达到 4.5 分及以上的题目比例，反映生成题目的高质量占比。

# Win Rate 评估
虽然 LLM Judge 可以提供多维度的绝对评分，但还需要一个相对评估指标来衡量生成题目与真题的质量差距

Win Rate 评估通过成对对比的方式，让 LLM 直接判断生成题目和真题哪个更好，这种相对比较比绝对评分更符合人类的判断习惯，也更容易发现生成题目的相对优势和劣势

评估指标：
1、胜率：生成题目被判定为更好的比例，反映生成题目相对于真题的优势
2、败率：真题被判定为更好的比例，反映生成题目相对于真题的劣势
3、平局率：两者被判定为质量相当的比例，反映生成题目与真题的相似程度


# 人工验证
尽管 LLM Judge 和 Win Rate 可以自动化评估题目质量，但对于数学题目这种需要严格逻辑推理的内容，人工验证仍然是不可或缺的。特别是在评估答案生成质量时，需要人类专家验证答案的准确性、解答步骤的完整性和数学推理的严密性

在我们的实现中，人工验证通过以下步骤进行：
1、阅读题目、答案、解答
2、评分（1-5 分）：正确性、清晰度、难度匹配、完整性
3、标注状态：
    approved（通过）
    rejected（拒绝）
    needs_revision（需修改）
4、添加评论

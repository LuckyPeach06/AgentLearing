# 阻塞项：工具工作目录为空 + codebase_path 用相对路径

## 现象
- 工具 cwd = /mnt/d/myCode，`ls -la` 只有 . 和 ..（空目录），`pwd` 确认。
- 真实代码在 /mnt/d/Work/agentLearning/base/myCode（5372 行 py）。

## 根因
1. codebase_maintainer.py:459 `codebase_path="../../myCode"` 是相对路径，按进程 CWD 解析。若从 ch9 目录启动则指向 base/myCode；若 CWD 是别处（如 /mnt/d），就会解析到一个空/错误目录 —— 本会话正是如此。
2. TerminalTool 白名单/沙箱：`cd` 到工作目录外被拒；含 `;` 的复合命令被拒；`git` 不在白名单（无法做 git status/log/blame 类质量检查）。

## 影响
- 本轮"探索/分析"几乎无法通过 TerminalTool 完成，只能靠 find/cat 绝对路径绕过。
- 仓库根目录散落多个笔记/数据目录（agentLearning_notes、agent_learning_notes、project_notes、knowledge_base、agent_learning_kb、data_science_kb、memory_data、learningNote）以及一个畸形目录 `D:\WorkgentLearning`（Windows 反斜杠未转义造成）——都是相对路径 workspace 的副产物。

## 建议
- codebase_path 改为绝对路径或 `Path(__file__).resolve().parents[1]` 推导。
- NoteTool 与其他 workspace 统一到 `<repo>/.agent_workspace/<project>/`，避免根目录污染。
- TerminalTool 白名单补 git（status/log/diff）。
- 修复 Windows 路径转义，删除 `D:\WorkgentLearning` 脏目录。

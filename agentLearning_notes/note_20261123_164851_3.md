# myCode 代码结构探索结论

base/myCode 是按章节组织、跟随 HelloAgents 教程递进的学习代码库，不是单一可运行应用：
- ch4：手写底层实现（core/Agent+Config+Message+HelloAgentsLLM；react/reflection/plan_and_solve 三大范式）
- ch7：基于 hello_agents 框架重写（agents 继承框架基类，tool 自研工具系统，llm 自定义 ModelScope provider，tests、vllm）
- ch8：记忆与 RAG 学习章节（本地记忆框架骨架 + hello_agents MemoryTool/RAGTool 示例 + Gradio PDF 助手）
- ch9：长程/上下文工程章节（CodebaseMaintainer 为可运行主线，依赖安装版 hello_agents；本地 ContextBuilder/NoteTool 是教程跟敲副本）
依赖：安装版 hello_agents==0.2.9，.env 在仓库根目录，脚本通过 sys.path 插入仓库根目录运行。
已知问题：README 只覆盖 ch4/ch7；ch8 多处占位类与 __init_.py 拼写错误；ch8 MemoryManager 导入失败；ch9 本地 ContextBuilder 缺 build()/_parse_*，ContextConfig 字段拼写 reserve_radio；ch9 本地 NoteTool 无父类却调用 super().__init__。
